# سایت خبر فوری خرداد آنلاین

سایت خبری کامل پایگاه خبری خرداد آنلاین — قالب حرفه‌ای به سبک بی‌بی‌سی فارسی.

- **آدرس موقت:** https://mohsensohrabi91-a11y.github.io/
- **دامنهٔ اصلی (بعداً وصل می‌شود):** khordadonline.com

## ساختار سایت

| فایل | توضیح |
|---|---|
| `index.html` | صفحهٔ اصلی — خبر اصلی، خبرهای مهم، آخرین خبرها، بخش‌های ایران/جهان/ورزش |
| `article.html?id=…` | صفحهٔ هر خبر با متن کامل و خبرهای مرتبط |
| `section.html?cat=…` | صفحهٔ بخش‌ها: `iran`، `world`، `sport`، `breaking`، `all` |
| `news.json` | منبع همهٔ خبرها (جدیدترین اول) |
| `style.css` | استایل قالب (هدر مشکی، قرمز BBC) |
| `app.js` | منطق رندر صفحه‌ها |

## افزودن خبر جدید

فقط `news.json` را ویرایش کن — خبر جدید **اول فایل**:

```json
{
  "id": 72110,
  "cat": "iran",
  "breaking": true,
  "time": "2026-11-14T09:00:00+03:30",
  "title": "تیتر خبر",
  "summary": "خلاصهٔ یک‌خطی",
  "body": ["پاراگراف اول متن کامل خبر.", "پاراگراف دوم."],
  "link": "https://t.me/khordadonline1/72110",
  "image": "https://cdn4.telesco.pe/file/…"
}
```

- `cat`: ‏`iran` | ‏`world` | ‏`sport`
- `breaking: true` → کارت بزرگ قرمز + نوار خبر فوری
- `image`: آدرس عکس پوستر خبر از کانال تلگرام (قسمت بالای پوستر به‌صورت خودکار برش می‌خورد)
- صفحهٔ اصلی هر ۶۰ ثانیه خودکار تازه می‌شود؛ خبر جدید بدون تغییر بقیهٔ فایل‌ها همه‌جا دیده می‌شود.

## اتصال دامنهٔ اختصاصی (بعداً)

۱. بازگرداندن فایل `CNAME` با محتوای `khordadonline.com`
۲. رکوردهای DNS در هاست ایران: چهار رکورد A برای `@` به `185.199.108.153` / `.109` / `.110` / `.111` + رکورد CNAME برای `www` به `mohsensohrabi91-a11y.github.io`
۳. فعال‌کردن Enforce HTTPS در Settings → Pages بعد از propagate شدن DNS
