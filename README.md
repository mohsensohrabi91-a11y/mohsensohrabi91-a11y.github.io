# سایت خبر فوری خرداد آنلاین

سایت استاتیک رایگان روی GitHub Pages با دامنهٔ khordadonline.com.

## به‌روزرسانی خبرها

فقط فایل `news.json` را ویرایش کن — خبر جدید را **اول فایل** اضافه کن:

```json
{
  "id": 72105,
  "title": "تیتر خبر",
  "summary": "خلاصهٔ یک‌خطی (می‌تواند خالی باشد)",
  "time": "2026-11-13T23:05:00+03:30",
  "breaking": true,
  "link": "https://t.me/khordadonline1/72105"
}
```

- `breaking: true` خبر را در کارت بزرگ بالای صفحه و نوار قرمز نشان می‌دهد.
- سایت هر ۶۰ ثانیه `news.json` را تازه می‌کند؛ نیازی به تغییر HTML نیست.
- حداکثر ~۱۵ خبر نگه دار؛ قدیمی‌ها را حذف کن.
